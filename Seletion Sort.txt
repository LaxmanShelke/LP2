def selection_sort(arr):

    n = len(arr)

    for i in range(n):

        min_index = i

        for j in range(i + 1, n):

            if arr[j] < arr[min_index]:
                min_index = j

        arr[i], arr[min_index] = arr[min_index], arr[i]

    return arr

numbers = list(map(int, input("Enter numbers: ").split()))

sorted_list = selection_sort(numbers)

print("Sorted List:", sorted_list)

Selection Sort is a simple sorting algorithm based on the Greedy Method.

A greedy algorithm makes the best possible choice at each step to achieve the overall solution.

In Selection Sort:

The smallest element is selected at every step
It is placed in its correct sorted position

**follows the greedy approach.
The Greedy Method is an algorithmic technique where:

The best immediate solution is selected
Without considering future consequences
Step-by-step optimal choices are made

**Selection Sort Using Greedy Approach

Selection Sort repeatedly:

Finds the minimum element
Places it at the beginning
Continues for remaining unsorted elements

At every iteration, the algorithm greedily selects the smallest element.

**Selection Sort Algorithm
Step 1:Start from first element.

Step 2:Find minimum element in unsorted part.

Step 3:Swap minimum element with current position.

Step 4:Move to next position.

Step 5:Repeat until array becomes sorted.

**Time Complexity

Best Case:O(n2)

Average Case:O(n2)

Worst Case:O(n2)

Space Complexity:O(1)
